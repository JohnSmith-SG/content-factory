# content-factory — описание проекта

## Название

**content-factory** — конвейер генерации и автопубликации постов для
Telegram-канала на стыке искусственного интеллекта и корпоративного
управления.

## Проблема

Вести тематический экспертный канал вручную — это каждый день один и тот
же цикл: найти свежий релевантный материал (исследование, гайд регулятора,
новость), вычленить в нём факты и цифры, написать пост так, чтобы он был
полезен практику, а не звучал как пресс-релиз, сделать к нему картинку без
артефактов, проверить факты и стиль, оформить, опубликовать в нужное
время. Это 40–60 минут сосредоточенной работы в день и высокий риск
пропустить день или опубликовать неточность.

## Пользователь

- **Основной:** автор канала — преподаватель корпоративного управления,
  которому нужно регулярно и без ошибок публиковать экспертный контент,
  тратя на это минуты, а не часы.
- **Читатели канала:** эксперты по корпоративному управлению, комплаенсу,
  риск-менеджменту, HR — те, кому важно понимать, как ИИ меняет работу
  советов директоров.
- **Как шаблон:** любой, кто ведёт тематический Telegram-канал и хочет
  такой же конвейер под свою тему (разворачивается по скиллу проекта).

## Основная функция

| | |
|---|---|
| **Вход** | ничего обязательного. По умолчанию `content-researcher` сам берёт следующий неиспользованный источник из `context/sources.md` или ищет свежую публикацию по теме. Можно задать конкретную ссылку или тему. |
| **Обработка** | ролевой конвейер из 4 субагентов Claude Code под оркестратором: выбор источника, сверка фактов с первоисточником и черновик → генерация картинки (MCP fal.ai) → содержательное ревью → механическая публикация |
| **Выход** | опубликованный в Telegram пост (картинка + подпись + продолжение + кнопка «English version»), английская версия по запросу в личке бота |
| **Инструменты** | Claude Code (субагенты, скиллы), MCP-сервер fal.ai (картинки), Telegram Bot API, systemd на VPS (расписание) |

## Формат результата

- JSON-файл поста в `posts/` (русский + английский тексты, `image_prompt`,
  статус) — единый источник истины.
- Картинка `.jpg` в `images/`.
- Пост в канале `@ai_pro_cg`, публикуется автоматически по будням в
  7:30 МСК.
- HTML-превью, эмулирующее вид поста в Telegram, — для согласования перед
  постановкой в очередь (дальше — автопубликация сервером по расписанию).

## Минимальный функционал (MVP — реализовано)

- Конвейер из 4 субагентов + скилл-оркестратор `content-pipeline`.
- **Автономный подбор источника:** без темы и ссылки `content-researcher`
  сам выбирает следующий приоритетный неиспользованный источник из
  `context/sources.md` либо ищет свежую релевантную публикацию.
- Команда `/new-post` — один пост от выбора источника до превью автономно.
- Статусная модель `draft → reviewed → approved → published` с
  единственной ручной точкой — одобрением превью, которым человек ставит
  пост в очередь (сам факт публикации в назначенный день выполняет сервер).
- Генерация картинок через MCP fal.ai + обязательная визуальная проверка
  на артефакты.
- Содержательное ревью (`governance-coach`) глазами директора по КУ —
  тезис, структура, факты, а не только орфография.
- Реальная автопубликация по расписанию на VPS (systemd-таймер), без ИИ
  на сервере.
- Кнопка «English version» под постом (deep link + проверка подписки).
- Модерация комментариев в группе-обсуждении.
- Сбор комментариев подписчиков для разбора и самообучения правил.

**Планы (за рамками MVP):** зеркальная публикация английской версии в
Facebook; вынести параметры канала из кода в конфиг; веб-панель статуса
очереди.

## Технологии

- **Claude Code** — субагенты (`.claude/agents/`), скиллы
  (`.claude/skills/`), оркестрация.
- **Python 3** (стандартная библиотека, без зависимостей) — серверные
  скрипты `publish.py`, `bot_listener.py`.
- **MCP-сервер fal.ai** — генерация изображений.
- **Telegram Bot API** — публикация, кнопки, модерация.
- **systemd** (Ubuntu 24.04) — таймер и сервис-листенер на VPS.
- **PuTTY plink/pscp** — доставка одобренных постов на сервер.
- Форматы: JSON (посты), Markdown (скиллы, доки), HTML (превью).
